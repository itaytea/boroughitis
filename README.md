# Boroughitis

A daily Wordle-style game for the 564 municipalities of New Jersey.

## How it works

- Each day, a mystery NJ municipality is chosen
- You start with its outline silhouette
- You have 6 guesses
- Each guess returns a 5-column comparison row:
  - **Name** — green if correct, yellow if your guess borders the answer
  - **Type** — green if same type (borough / township / city / town / village)
  - **County** — green if same county, yellow if adjacent county
  - **Population** — arrow indicating whether the mystery muni is bigger or smaller
  - **Direction** — compass arrow pointing from your guess toward the answer

## Project layout

Everything the site needs lives at the repo root (there is no `/web` folder):

```
index.html               # the whole game page
game.js                  # game logic
styles.css
/data
  municipalities.json    # 564 munis, generated by build_data.py
  counties.json          # 21 counties + adjacency
  schedule.json          # optional explicit daily answer list
  outlines/              # one SVG per municipality
/scripts
  build_data.py          # one-time data builder
  requirements.txt
```

## Under the hood

**Data pipeline.** `scripts/build_data.py` downloads the NJ county-subdivision
shapefile from Census TIGER/Line and 2020 Decennial Census populations, joins
them, and drops entries with no population (non-municipality subdivisions).
It reprojects to NJ State Plane to compute neighbor adjacency (which munis
share a border) and writes `data/municipalities.json` (id, name, type, county,
population, lat/lng centroid, borders), `data/counties.json` (county adjacency
derived from muni borders), and one normalized SVG silhouette per muni in
`data/outlines/`. Downloads are cached in `scripts/_cache/` (git-ignored).

**Daily answer.** The site is static and everyone sees the same puzzle. The
client computes the current UTC day number and picks the answer from
`data/schedule.json` (a `start_date` plus a list of muni ids) while inside
that range. Past the end of the schedule, or with no schedule, it falls back
to a hash of the day number modulo the muni count. Guesses and stats are kept
in the browser's localStorage.

## Data sources

- US Census TIGER/Line shapefiles (municipality boundaries)
- 2020 Decennial Census (population)
- NJ Department of Community Affairs (municipality types)

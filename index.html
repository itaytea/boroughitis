How to play

Guess the mystery NJ municipality in 6 tries.

You start with its outline. Each guess gives you five hints:

  • Name — green if correct, yellow if your guess borders the answer.
  • Type — green if same type (boro / township / city / town / village).
  • County — green if same county, yellow if adjacent county.
  • Pop. — arrow points toward the answer's population.
  • Dir. — compass arrow points toward the mystery municipality.

New puzzle daily. Same answer for everyone, worldwide.
